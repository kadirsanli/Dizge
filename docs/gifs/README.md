# Uygulama kayıtları

Bu GIF'ler örnek HTML'lerin gerçek tarayıcı ekranlarından alınan karelerle oluşturulmuştur. Yapay görsel veya önceden hesaplanmış bir animasyon değildir. Kamera klavyeyle, fizik/dalga ilerlemesi uygulamanın adım düğmesiyle kontrol edilmiştir.

Kareler uygulamanın görsel alanına kırpılmış, 360×300'e sığdırılmış ve 64 renkli GIF olarak kodlanmıştır. Oynatma hızlandırılmıştır; gerçek FPS veya CPU performansı iddiası taşımaz. N-cisim ve dalga simülasyonları sayısal yaklaşık modellerdir.

Kare sayısı, boyut ve dosya boyutları `kayitlar.json` içindedir. Başlangıç ayarları örneklerin kaynaklarında, performansın ham verileri ise ilgili test JSON dosyalarındadır.
